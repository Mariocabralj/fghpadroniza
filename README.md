Tipo: Aplicativo Web Institucional

📌 OBJETIVO PRINCIPAL
Criar um assistente de padronização documental para líderes de setores . O sistema permite que usuários enviem rascunhos, documentos brutos ou apenas descrevam uma ideia, e o app automaticamente organiza, estrutura no padrão institucional e gera um documento .DOCX pronto para baixar ou para envio à qualidade.

📝 OBSERVAÇÕES IMPORTANTES
O sistema é para líderes de setor, não para o setor da qualidade
Foco em transformar rascunhos em documentos padronizados
Interface deve ser intuitiva e auto-explicativa
Sugestões práticas ajudam o usuário a fornecer informações completas
Split view permite comparação lado a lado
Checklist automático garante conformidade
Exportação em .DOCX é funcionalidade crítica
Email para qualidade com mailto: facilita o envio
